# Проект лендинга Tilda Publishing

Шаблон главной страницы промо-сайта конструктора сайтов Tilda.

## Описание
Лендинг презентует возможности AI-конструктора Tilda. Основная цель — конверсия пользователя в регистрацию.

## Особенности верстки
*   **Чистый HTML/CSS:** Код адаптирован для ручной правки вне конструктора.
*   **Адаптивность:** Используются медиазапросы для корректного отображения на мобильных устройствах (согласно брейкпойнтам Tilda: 320, 480, 640, 960, 1440px).
*   **Типографика:** Используется фирменная гарнитура `Tilda Sans`.
*   **Интерактивность:** Встроены кастомные JS-скрипты для инициализации анимаций при скролле и работы каруселей (слайдеров).

## Структура файлов
*   `index.html` — Главная страница.
*   `css/styles.css` — Основной файл со стилями компонентов.
*   `README.md` — Данный файл.

## Как запустить локально

1.  Скопируйте содержимое папки проекта на свой компьютер.
2.  Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Safari, Edge).
3.  Для редактирования используйте любой текстовый редактор (например, VS Code).

**Важно:** Так как изображения загружаются по абсолютным путям (CDN Tilda), для оффлайн-просмотра убедитесь, что у вас есть доступ к сети Интернет, либо скачайте картинки локально и пропишите относительные пути в атрибутах `src` и `background-image`.
